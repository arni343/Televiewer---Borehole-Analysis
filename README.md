# Televiewer---Borehole-Analysis
This is a repository containing progress through the development stages of code used for automating interpretation of borehole analysis as part of a research project in collaboration with Robertson Geologging. This project investigates integration of machine learning methods to existing image processing techniques to visually extract, analyse and  study sinusoidal fractures caused in boreholes used by geologists, based on which dip angle, amplitude and phase of the sinusoidal fractures is calculated.
